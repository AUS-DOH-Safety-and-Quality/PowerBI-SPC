# Settings Options

This page summarises the usage and options for each of the Settings menus provided by the visual.
Each page lists every setting in its format-pane card, generated from the visual's setting definitions. Most settings other than on/off toggles can also be set with conditional formatting, which takes a drop-down's value as shown in `code`.
